      Asset packs

      Packs are ordinary folders under assets/packs. Drop a folder of PNGs in and press rescan — anything inside a terrain folder becomes a brush texture, anything else becomes a stamp. Files you import here land in the user pack.

      Projects

      Every map is a folder under projects containing a readable project.json. Copy one to back it up; delete one to remove it.

      Extensions

      Every folder under extensions/ that contains an extension.json is loaded at startup and can add tools, layer types, panels, commands and export formats. Three worked examples ship with the program; EXTENSIONS.md documents the API they use. Extensions are ordinary JavaScript running with the same reach as the editor — read one before you enable it.
