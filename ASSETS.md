# Art: where it comes from, and how to add your own

Cartograph ships with no downloaded art at all. Everything in the starter pack
is **generated by code in this repository** the first time you run the program,
which means there is nothing in here whose licence anyone has to take on trust.

## The starter pack

`tools/terrain.py` writes seamless terrain tiles; `tools/stamps.py` writes the
map symbols as SVG. Both are seeded, so the pack is reproducible:

```
python app.py --regen-pack --seed harbour
```

That rewrites `assets/packs/starter` from scratch. The seed is recorded in the
pack's `pack.json`, so a pack you liked can always be rebuilt.

The generated pack is **CC0 1.0** — public domain. Maps you make with it are
yours, commercially or otherwise.

Seventeen terrain tiles (parchment, ocean, shallows, grass, meadow, broadleaf
and pine forest, sand, dunes, rock, highland, snow, tundra, marsh, farmland,
ashland) and twenty-nine symbols in three random variants each: mountains,
hills, volcanoes, caves, standing stones, five kinds of tree, villages, towns,
cities, castles, towers, ruins, windmills, lighthouses, mines, bridges, ships,
a sea serpent and a compass rose.

## Adding your own

Two ways, and they end up in the same place.

**From inside the program.** Assets tab → *Import files…*. Pick whether they are
textures (seamless tiles for the brush) or stamps (symbols you place), give them
a group name, and they are copied into `assets/packs/user`. They appear in the
pickers immediately — no restart.

**By copying a folder.** A pack is just a folder under `assets/packs`. Drop one
in and press *Rescan folder*. If it has no `pack.json`, Cartograph indexes it by
looking at the folder names:

```
assets/packs/my-pack/
  terrain/          <- anything in here becomes a brush texture
    marsh.png
  stamps/           <- anything in here becomes a stamp
    ruins/
      broken-tower.png     <- the sub-folder becomes the group name
  pack.json         <- optional; if present it wins
```

`png`, `jpg`, `webp`, `svg` and `gif` are all recognised. SVG is worth using for
symbols — it stays sharp at print resolution.

A `pack.json` lets you set the licence and per-asset labels:

```json
{
  "name": "Coastal Extras",
  "author": "you",
  "license": "CC-BY-4.0",
  "assets": [
    { "id": "sea-stack", "kind": "stamp", "label": "Sea Stack",
      "group": "coast", "file": "stamps/sea-stack.png" }
  ]
}
```

Whatever you put in `license` is shown on the Assets tab, so a pack you did not
make yourself is never sitting in your library unlabelled.

## Where to find more, legitimately

These are the places worth looking for art you can actually redistribute. All of
them are free; check each asset's own licence line before you rely on it.

| Source | Licence | Good for |
|---|---|---|
| [ambientCG](https://ambientcg.com/) | CC0 1.0 — [licence terms](https://docs.ambientcg.com/license/) | Seamless ground textures: grass, gravel, rock, sand, snow |
| [OpenGameArt — CC0 collections](https://opengameart.org/content/cc0-tiles-tilesets) | CC0 (per-asset, check the page) | Tiles, terrain, map symbols |
| [OpenGameArt — Cartography Pack](https://opengameart.org/content/cartography-pack) | see the asset page | Map symbols in an old-atlas style |
| [Kenney](https://kenney.nl/assets/map-pack) | CC0 1.0 | Clean top-down map tiles and icons |
| [ShareTextures](https://www.sharetextures.com/) | CC0 | Ground and paper textures |

Download a pack, drop the folder into `assets/packs`, add a `pack.json` with the
licence, press Rescan. Nothing is fetched over the network by the program
itself — that is a deliberate choice, so the program keeps working on a machine
that has never been online.

## Terrain tiles need to tile

A texture is repeated across the map, so a tile with a visible seam will show it
a hundred times. The generated ones wrap by construction. If you make your own,
check it against itself before you rely on it — most image editors have an
offset-by-half filter that makes a bad seam obvious immediately.
